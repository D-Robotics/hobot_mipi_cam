# mipi\_cam的评测方案

# 一、重新定义评测范围和核心指标

建议分成六个评测模块，总分仍然为100分，但提高时间同步和多传感器数据关联的权重。

说明：双目在lpwm模式下，已经通过硬件实现左右目曝光的同步。IMU的时间戳已经通过中断方式精确到采集时间点的时间戳。

1. 评测方案分为两个维度：

    1. Camera 设备自身性能评测（Device\-side）：评估摄像头硬件、图像采集能力、驱动稳定性、图像质量、时间戳及资源消耗。

    2. ROS2 Topic 数据链路评测（Receiver\-side）：评估从 Camera 发布 ROS2 Topic 到外部 ROS2 节点接收数据的完整链路，包括数据完整性、传输延迟、吞吐量、丢帧率、抖动及长期稳定性。

3. ROS2 Topic 外部接收性能评测

这一部分建议作为独立的评测模块，重点验证外部 ROS2 节点是否能够稳定、高效、完整地接收 Camera Topic 数据。所以需要需时mipi\_cam的log输出最少的时候测试，避免出口输出影响性能。同设备下的其他进程的订阅者。

# 二、测试方案

方案开发原则：

1. 对于评估设备自身的能力指标，需要在程序里增加相关的log记录相关信息。

2. 对于接收topic的测试用例采用支持ros的python编程。

3. 测试用的启动脚本增加ros2 launch脚本。

4. 通过skill启动测试用例，以及相关统计信息，以及编写测试报告。

# 三、测试报告
